# ASTRA Sandbox

ASTRA Sandbox is an educational experiment for exploring how changes in astronaut health indicators might be monitored and explained. Its goal is to make the concepts of personal baselines, changing measurements, and understandable alerts easier to learn and discuss.

## Current status

The project is in its foundation and documentation phase. There is no runnable application, analysis engine, dataset, API, or user interface yet.

The future concept is to use synthetic readings for a fictional person, compare new readings with that person's baseline, and present changes together with a clear reason for each observation or alert. A baseline is the personal reference against which later readings are compared.

This is a proposal, not an implemented system. ASTRA Sandbox is not a medical device, is not a NASA product or endorsement, and is not a confirmed Space Apps submission. Any official challenge fit, participation requirements, or preparatory work must be verified separately before implementation.

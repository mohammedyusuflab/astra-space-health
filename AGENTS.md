# Working Rules

- Work only on the explicitly assigned task, then stop for review.
- Keep the solution simple and understandable for a solo beginner developer.
- Read documentation related to the task and keep it consistent.
- The current phase is documentation only. Programming requires an explicit task from the project owner after requirements review.
- Do not add libraries, services, or tools outside the task scope.
- Do not invent NASA requirements, data sources, or test results.
- Clearly distinguish synthetic data from real data and proposals from implemented features.
- Report changes and verification results honestly.
- Wait for user review before committing. Do not push, create a pull request, merge, or deploy without an explicit request.
